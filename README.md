# CardStudio – کارت استودیو

اپلیکیشن اندروید برای ساخت کارت تبریک، کارت‌پستال و دعوت‌نامهٔ دیجیتال؛ ساخته‌شده با HTML/CSS/JS و Capacitor، **آفلاین**، با APK ساخته‌شده توسط GitHub Actions.

- شناسهٔ اپ: `com.cardstudio.invitation`
- ۶۰ مناسبت در ۴ گروه × بیش از ۲۰ قالب متفاوت برای هر مناسبت (۲۴۴۰ قالب، ۲۱ سبک)
- ۷ زبان کارت: فارسی، عربی، انگلیسی، ترکی، روسی، فرانسوی، آلمانی (راست‌به‌چپ و اتصال حروف درست)
- ویرایشگر کامل (لایه، چندانتخابی، راهنما/شبکه، زوم، قفل، شفافیت، کپی استایل، Undo/Redo، چندصفحه‌ای)
- فرم اطلاعات اختیاری که در قالب‌ها خودکار جایگذاری می‌شود
- خروجی PNG / JPG / PDF / استوری / پست / واتساپ / چاپ / ZIP، اشتراک‌گذاری، ذخیره در گالری
- کارت گروهی از CSV / Excel(xlsx) / متن چسبانده‌شده؛ مدیریت مهمان‌ها و وضعیت پاسخ
- دعوت‌نامهٔ هوشمند (لینک شخصی، نقشه، مسیریابی، شمارش معکوس، افزودن به تقویم، تأیید حضور، همراه)
- کارت متحرک: ورود متن، افکت باز شدن، ذرات، موسیقی (فایل خود کاربر)، خروجی GIF و ویدیو (MP4 یا WebM)
- کتابخانهٔ گرافیکی برداری آفلاین، گالری/پوشه/نسخه/علاقه‌مندی، قالب شخصی
- پیشنهاد متن آفلاین (۷ لحن) و هوش مصنوعی آنلاین اختیاری (کلید خود کاربر)

## ساخت APK
Actions → **Build Android APK** → Run workflow (یا هر push). فایل `app-debug.apk` هم Artifact است و هم در Releases.

## دعوت‌نامهٔ هوشمند
صفحهٔ `www/invite/` استاتیک است و باید روی میزبان ثابت (مثلاً GitHub Pages؛ ورک‌فلوی `pages.yml` آماده است) منتشر شود. نشانی آن را در تنظیمات اپ وارد کنید. اطلاعات دعوت در fragment لینک می‌ماند و به هیچ سروری ارسال نمی‌شود. پاسخ مهمان به‌صورت کد `CS1-…` (واتساپ/کپی) یا اختیاری از طریق Webhook می‌آید و در بخش «مهمان‌ها» ثبت می‌شود.

## پرداخت
هیچ پرداخت نمایشی وجود ندارد. معماری `www/js/core/entitlements.js` فقط یک رابط (`registerProvider`) دارد؛ تا زمانی که سرویس واقعی (Google Play Billing، بازار، Stripe …) متصل نشود، قالب‌های ویژه قفل و خروجی رایگان دارای نشان CardStudio است. برای آزمایش توسعه‌دهنده: در تنظیمات ۷ بار روی شمارهٔ نسخه بزنید.

## توسعه
```
npm install && node scripts/install-fonts.mjs
node scripts/test-logic.mjs      # تست‌های منطق
node scripts/serve.mjs . 8123    # http://localhost:8123/www/index.html
```
بسته‌های قالب جدید با `registerPack()` در `templates/registry.js` اضافه می‌شوند.
