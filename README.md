# CardStudio Pro – کارت‌استودیو

اپلیکیشن موبایل‌پسند ساخت کارت‌پستال، کارت تبریک و دعوت‌نامه دیجیتال با پشتیبانی فارسی و راست‌چین.

## امکانات
- قالب عروسی، تولد، عاشقانه، تبریک، مذهبی، تشکر، تسلیت و عمومی
- ویرایش نام گیرنده/فرستنده، عنوان، شعر و پیام دلخواه
- انتخاب تم رنگی، فونت و انیمیشن
- افزودن عکس و موسیقی از گوشی
- پیش‌نمایش زنده، ذخیره محلی، لینک اشتراک و خروجی PNG
- ساخت ویدئوی متحرک WebM همراه موسیقی (بسته به پشتیبانی مرورگر)
- PWA و بسته‌بندی Android با Capacitor

## اجرای وب
```bash
npm install
npm run prepare-web
npm run serve
```
سپس `http://localhost:8080` را باز کنید.

## ساخت اندروید
```bash
npm install
npm run prepare-web
npx cap add android
npx cap sync android
npx cap open android
```
همچنین workflow با نام **Build Android APK** در GitHub Actions برای ساخت APK آزمایشی آماده شده است.

## محدودیت اشتراک
لینک کارت، متن و طراحی را منتقل می‌کند؛ فایل موسیقی و عکس محلی به‌صورت خودکار آپلود نمی‌شوند. برای ارسال کارت متحرک همراه موسیقی از خروجی ویدئویی استفاده کنید. پشتیبانی از WebM و اشتراک مستقیم به گوشی و مرورگر بستگی دارد.
