# CardStudio Pro – کارت‌استودیو

برنامه‌ای موبایل‌پسند برای طراحی کارت‌پستال، تبریک و دعوت‌نامه دیجیتال؛ قابل اجرا در مرورگر و قابل بسته‌بندی برای Android با Capacitor.

## امکانات

- طراحی کارت با هزاران ترکیب قالب از مناسبت‌ها و سبک‌های مختلف
- رابط فارسی و انگلیسی و پشتیبانی کارت از فارسی، انگلیسی، عربی و زبان‌های دیگر
- طراح پیشنهاددهنده: ساخت چند طرح بر اساس مناسبت، رنگ و سبک؛ تحلیل آنلاین توضیح کاربر با API سازگار با OpenAI در صورت افزودن کلید شخصی در تنظیمات
- ویرایشگر Canvas با لایه‌ها، صفحه‌ها، متن، تصویر، شکل، QR، فونت و افکت
- کتابخانه فونت فارسی و لاتین، به‌علاوه امکان بارگذاری فونت شخصی از TTF/OTF/WOFF/WOFF2
- پاکت دعوت تعاملی با افکت سه‌بعدی، انتخاب ظاهر، نمایش نام گیرنده، افزودن به تقویم و ثبت پاسخ حضور
- مدیریت رویداد و مهمان، لینک اختصاصی هر مهمان، کد پاسخ و داشبورد آمار حضور
- کتابخانه موسیقی آماده با اطلاعات منبع و مجوز، انتخاب فایل MP3/WAV شخصی، زمان شروع و بلندی صدا
- کارگاه حرفه‌ای برای تنظیم زمان شروع، مدت و نوع ورود هر لایه، پیش‌نمایش و خروجی ویدئو با موسیقی انتخاب‌شده
- خروجی PNG، JPG، PDF، GIF و ویدئو؛ اشتراک فایل با قابلیت‌های دستگاه
- ذخیره محلی کارت‌ها و داده‌ها، PWA و بسته‌بندی Android بدون نیاز به سرور برای طراحی روزمره

## اجرای نسخه وب

```bash
npm install
npm run prepare-web
npm run serve
```

سپس `http://localhost:8080` را باز کنید.

## ساخت APK اندروید

```bash
npm install
npm run prepare-web
npx cap add android
npx cap sync android
npx cap open android
```

GitHub Actions نیز با هر تغییر مرتبط، نسخه وب را به GitHub Pages می‌فرستد و APK آزمایشی می‌سازد.

## تنظیمات و محدودیت‌های مهم

- طراح آفلاین برای پیشنهاد قالب و ترکیب‌بندی به کلید API احتیاج ندارد. تحلیل آنلاین متن فقط وقتی فعال می‌شود که مالک برنامه endpoint و کلید API خودش را در تنظیمات وارد کند.
- موسیقی آماده در زمان build از منابع دارای مجوز دریافت می‌شود؛ برای کار کاملاً آفلاین، برنامه باید یک بار کتابخانه را دریافت و cache کرده باشد. فایل صوتی شخصی به‌صورت داده محلی روی همان کارت ذخیره می‌شود.
- پاسخ مهمان‌ها در حالت پایه با کد پاسخ و ورود آن به برنامه مدیریت می‌شود؛ برای ثبت خودکار روی یک سرور، باید webhook مورد اعتماد تنظیم شود.
- فروش واقعی قالب‌ها فعال نیست تا زمانی که یک ارائه‌دهنده پرداخت واقعی متصل و آزمایش شود. نمایش قالب ویژه به‌تنهایی به معنی امکان دریافت وجه نیست.
- فایل خروجی ویدئو به پشتیبانی MediaRecorder دستگاه/مرورگر بستگی دارد. در دستگاه‌های ناسازگار از GIF یا PNG استفاده کنید.
- اشتراک لینک دعوت و ارسال فایل HTML پاکت، دو روش جدا هستند؛ ارسال فایل به‌جای لینک به پشتیبانی Web Share دستگاه بستگی دارد.
